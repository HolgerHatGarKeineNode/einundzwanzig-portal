# Security Policy

## Supported versions

The Einundzwanzig Portal is a continuously deployed application. Only the current state of the
`master` branch — and the production deployment at
[portal.einundzwanzig.space](https://portal.einundzwanzig.space) — receives security fixes.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues, pull requests or discussions.**

Report privately through
[GitHub Security Advisories](https://github.com/HolgerHatGarKeineNode/einundzwanzig-app/security/advisories/new).
That channel is private and lets us work on a fix with you before anything becomes public.

Please include:

- what the problem is and where (URL, route, endpoint, or file),
- the steps to reproduce it,
- what an attacker could reach with it,
- any log output, request/response pair or proof of concept you have.

## What to expect

- We aim to acknowledge a report within **72 hours**.
- You get an assessment and a planned fix date once the report is confirmed.
- We will credit you in the advisory unless you ask us not to.

## Scope

In scope: this repository and the portal deployments it powers
(`portal.einundzwanzig.space` and the national domains pointing to it).

Out of scope: findings that require physical access or a compromised end-user device, reports
generated by an automated scanner without a demonstrated impact, missing hardening headers
without an exploitable consequence, and denial of service through sheer volume.

## Please do not

Access, modify or delete data that is not yours, run load or denial-of-service tests against
production, or use social engineering against contributors or users. Test against a local
installation wherever you can.
